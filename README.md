# ShipChain — Blockchain-Based Shipment Management System

A startup-oriented prototype for secure shipment tracking, blockchain verification and AI-powered logistics.

## Current MVP

- Responsive landing page
- Create shipment
- Automatic shipment ID
- Shipment tracking timeline
- Operations dashboard
- Browser-local prototype storage
- Architecture prepared for blockchain and AI integration

## Project roadmap

1. Frontend MVP
2. Node.js backend API
3. PostgreSQL/Supabase database
4. Solidity smart contract + Hardhat
5. Blockchain event verification
6. QR shipment tracking
7. Python/FastAPI AI delay prediction
8. Authentication and role-based dashboards
9. Cloud deployment
10. Logistics API integrations

## Important

The current version is a frontend prototype. It does **not** yet store real customer data on a server or execute blockchain transactions.

Never put passwords, API keys, private keys, or sensitive personal information in GitHub.
